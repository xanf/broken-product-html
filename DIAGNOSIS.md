# Лист діагностики — Зламаний продукт №1

## Тикет №1 — сайт без оформлення
- **Шар:** CSS.
- **Симптом:** На обох сторінках не підключалися стилі.
- **Інструмент:** Elements -> `link`.
- **Винуватець:** Тег `link`.
- **Причина:** Назву файлу стилів в тезі вказано некоректно.
- **Виправлення:** Перейменувати файл styles.css на style.css в обох файлах.
- **Перевірка:** Заходимо на сторінки і файл стилів підключено.

## Тикет №2 — губиться час початку
- **Шар:** HTML.
- **Симптом:** При надсиланні даних форми на request.html не надсилався час, а всі інші поля надсилались.
- **Інструмент:** Elements -> `form`.
- **Винуватець:** <input id="time" type="time" required>
- **Причина:** Не вказано атрибут name через, що час не надсилався.
- **Виправлення:** <input id="time" type="time" name="time" required>
- **Перевірка:** Вводимо дані на форму на сторінці request.html і натискаємо надіслати, і час початку надсилається.

## Тикет №3 — кнопка не натискається
- **Шар:** CSS.
- **Симптом:** Не виділяються елементи блоку с класом .hero у DevTools.
- **Інструмент:** Inspect element -> .hero.
- **Винуватець:** .hero::after.
- **Причина:** Псевдоелемент ::after блокує весь блок класу .hero.
- **Виправлення:** Видалити рядок з псевдоелементом ::after та попередньо перенести властивість background до класу .hero.
- **Перевірка:** На сторінці index.html працює кнопка "Показати" і випадаючий список "Мінімум місць".

## Тикет №4 — «немає кімнат», хоча є
- **Шар:** JS.
- **Симптом:** під час вибору місць для кімнати некорректо відображаються кімнати.
- **Інструмент:** Sources + breakpoint.
- **Винуватець:** неправильний filter у функції function applyFilter().
- **Причина:** використання у const filtered константи min не приведеної до числового типу викликало порівнювання кількості кімнат з текстом "0", а також зайва умова "&& room.seats === min".
- **Виправлення:** видалення зайвої умови "&& room.seats === min" та приведено константи min, під час її створення, до числового типу.
- **Перевірка:** фільтрація вибору кімнат працює корректно.
